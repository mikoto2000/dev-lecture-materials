# 検証記録

最終確認日 2026-11-11。

## Windows での実機確認

Windows 11、WSL / wslc 3.0.5.0、`postgres:17`（PostgreSQL 17.11）で確認しました。コンテナーと名前付きボリュームには検証専用の名前を使いました。

- PowerShell からイメージを取得し、ボリュームを作成して DB を起動
- `pg_isready` で接続受付を確認し、誤った TCP パスワードで接続が拒否されることを確認
- `wslc exec -it` で `Password:` からログインし、SQL を実行して `\q` で終了
- 配布 SQL の実行後、停止・再開とコンテナーの削除・再作成の両方で3行と更新値を確認
- Windows の `Test-NetConnection` で `127.0.0.1:15432` の TCP 接続に成功
- 検証用コンテナーとボリュームを削除し、一覧から消えたことを確認

WSL の新規インストール、WSL 2.9.3 での動作、Windows 側の SQL クライアントからのログインは未検証です。
