# 参考資料

- [MDN: HTTP レスポンスステータスコード](https://developer.mozilla.org/ja/docs/Web/HTTP/Reference/Status): ステータスの意味
- [Nginx: ngx_http_log_module](https://nginx.org/en/docs/http/ngx_http_log_module.html): ログ形式、`escape=json`、`$request_time` の単位
- [Apache: ログファイル](https://httpd.apache.org/docs/2.4/logs.html): アクセスログとエラーログ
- [PowerShell: ConvertFrom-Json](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/convertfrom-json): JSON の読み取り
- [Google SRE: Monitoring Distributed Systems](https://sre.google/sre-book/monitoring-distributed-systems/): トラフィック、エラー、遅延、飽和の観測
- [OWASP: Logging Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html): 記録すべき情報と機密情報の扱い
