# アクセスログ監視入門

Web サイトが「開ける」だけで、利用者が困っていないと言えるでしょうか。この教材では、アクセスログから **失敗したリクエストと遅いリクエストを見つけ、正常・異常・復旧を判断する**練習をします。

架空のログを使う60〜90分のハンズオンです。Windows PowerShell 5.1 または PowerShell 7 があれば進められます。Docker、Web サーバー、外部サービスへの登録は不要です。PowerShell の画面を開き、ファイルを保存したことがある方を想定しています。

## できるようになること

- 時刻、パス、HTTP ステータス、処理時間の意味を説明する
- 調査する時間帯と対象を決め、ログを絞る
- リクエスト数、5xx 率、遅いリクエスト数を計算する
- 母数と時間窓を付けて異常を判断し、復旧を確認する
- ログの途絶と正常を区別し、通知と調査の手順を考える
