# アクセスログ分析教材の検証記録

## 2026-11-20

- Windows / Node.js 24.22.1 / Python 3.12.10で配布物を生成した。
- `npm run test:log-analysis` で正常時60件、ガイド演習114件、総合演習154件と解説の件数を照合した。
- 時間範囲の開始を含む・終了を含まない挙動、形式エラー、認証結果の必須項目、上限行数を確認した。
- JSONLと内蔵サンプル、教材本文と同梱本文、ZIP内の全ファイルと配布元が一致することを確認した。
- ESLint、TypeScript、全教材のtextlint、サイトビルドと既存URL検査を実行した。
- FirefoxでローカルのHTMLを開き、画面表示を確認した。初期集計を停止させるフォームのメソッドとボタンIDの衝突を検出し、IDを修正した。衝突の再発を静的検査で確認する。
- 修正後のブラウザー通し操作は未確認。Computer UseはWindowsブラウザーのURLポリシーを適用できないため停止した。別ウィンドウのスクリーンショットは無関係のダッシュボードを含む可能性があるとして自動レビューで拒否され、取得していない。

ファイル選択、サンプル切り替え、条件変更、リセット、ZIP展開後の起動は、開催前に講師用ガイドに沿って受講者のブラウザーで確認する。
