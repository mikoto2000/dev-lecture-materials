# 不正アクセス教材の検証記録

## 2026-11-18

Loki 3.7.10、Grafana 13.3.1、Grafana Alloy v1.22.0、Python 3.12.14-slim を使用します。アクセスログ教材の検証後に、独立した9ページの教材と専用 ZIP を作成しました。

- Windows 上で、本文のリンク、目次、配布先、生成設定、ZIP とソースの整合性を確認
- WSL 2 / Ubuntu 24.04 の Python 3.12 で、実 HTTP の単体試験4件に成功
- 単体試験では、認証の成功・失敗、HTTP ステータスとの対応、パスワードや未知のアカウント名の非記録、クエリー文字列の除外を確認
- アプリが TCP 接続の送信元を記録し、任意の X-Forwarded-For を送信元として信用しないことを確認
- Windows 上で全教材の textlint、ESLint、TypeScript、サイトビルドを確認
- WSL 2 の Docker Engine 29.9.3 / Compose v5.7.0 で配布 ZIP を一時フォルダーへ展開し、専用プロジェクトとランダムポートで起動
- 認証失敗、固定3パスの探索、1パスのリンクミスで Firing と実際の firing 通知を確認。通知には client_ip、認証の通知には account が保持された
- 探索とリンクミスが別々の新しい通知を出したことを、受信器の履歴でも確認
- 各シナリオを normal に戻し、正常と新しい resolved 通知を確認。試験終了時に専用のコンテナーとボリュームを削除

配布 ZIP は共通のアクセスログラボの資材と専用アプリ・設定を梱包します。展開後は前の教材のフォルダーに依存しません。受講者の PC に Ruby や Python を直接導入する必要はありません。

ブラウザーの GUI 通し操作、Docker Desktop での通し操作、外部宛先や実アカウントによる実験、自動遮断は未実施です。認証はセッションやトークンを発行しない学習用の判定です。探索シナリオは固定した3つの存在しないパスへ低頻度でアクセスするもので、脆弱性の悪用は行いません。
