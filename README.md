# Rspress website

## Setup

Use Node.js 20.19+ or 22.12+ (Node.js 22 LTS recommended).

Install the dependencies:

```bash
npm ci
```

## Get started

Start the dev server:

```bash
npm run dev
```

Build the website for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
